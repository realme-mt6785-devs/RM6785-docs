title: Kernel Flashing Guide

import { Aside, Steps, Tabs, TabItem } from '@astrojs/starlight/components';

<Tabs>
  <TabItem label="First Method (recovery)">
    <Steps>

    1. Download the kernel zip.

    1. Reboot to recovery. This assumes you have a working
       custom recovery. Please visit [this section](../../appendix/recoveries)
       for list of recoveries.

    1. Flash the kernel zip from the recovery, just like
       how you flash a ROM.

    </Steps>
  </TabItem>
  <TabItem label="Second Method (fastboot)">
    <Steps>

    1. Download the kernel zip.

    1. Extract boot.img from the kernel zip.

    1. Boot the phone into bootloader (fastboot).

    1. Flash the boot.img:

       ```sh
       fastboot flash boot <drag and drop the boot.img>
       ```

    </Steps>
  </TabItem>
</Tabs>

<Aside type="note">
This actually works for recovery as well. For the
**First Method**, you can just flash the recovery zip.

As for the **Second Method**, replace *boot* with *recovery*,
and drag-and-drop the extracted recovery.img instead.
</Aside>
