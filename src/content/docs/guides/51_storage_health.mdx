There are two methods to do this.

## First method: WearLevelInsight app

Download the app [here](https://t.me/RM6785_Chat/387537).
Install it and give it root access.

## Second method: Manually via Termux

<Steps>

1. Enter root shell:

   ```
   su
   ```

1. Run this:

   ```
   cat /sys/devices/platform/bootdevice/health_descriptor/life_time_estimation_*
   ```

</Steps>

Here's what the output mean:

```
0x01 0x01 = 100-90% (good UFS health)
0x01 0x02 = 90-80%
0x01 0x03 = 80-70%
0x01 0x04 = 70-60%
0x01 0x05 = 60-50%
0x01 0x06 = 50-40%
0x01 0x07 = 40-30%
0x01 0x08 = 30-20%
0x01 0x09 = 30-20%
0x01 0x0A = 20-10% (RIP your UFS)
```
